## ▶️ How to Run

1. Clone or download this repository.
2. Open the `Week-1-Web-Development` folder.
3. Open `index.html` in Google Chrome or another modern web browser.
4. To test the Calculator, open its HTML file inside the `Calculator` folder.
5. To test the To-Do App, open `todo-index.html` inside the `To-Do` folder.
