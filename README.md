# Week 3 - Furnisher's Web

## Full-Stack Furniture E-Commerce Website

## Overview

Furnisher's Web is a full-stack furniture e-commerce website developed as the updated web version of my earlier Furnisher's .NET project.

The original desktop-based furniture management concept was redesigned and extended into a modern web-based e-commerce application using HTML, CSS, JavaScript, Node.js, Express.js and MySQL.

## Key Features

- Furniture product catalogue
- 20 furniture products
- Category-based product browsing
- Product details
- Product images
- Colour selection
- Quantity selection
- Add to Cart functionality
- Shopping cart management
- Automatic total price calculation
- User registration
- User login
- Checkout and billing
- Payment demo interface
- Order confirmation
- REST API integration
- MySQL database integration

## Technology Stack

**Frontend:** HTML5, CSS3, JavaScript

**Backend:** Node.js, Express.js

**Database:** MySQL, phpMyAdmin

**Tools:** Visual Studio Code, XAMPP, Git, GitHub, GitHub Pages

# Database

The Week 3 project uses a MySQL database named **ecommerce_db**.

## Main Tables

- products
- users
- orders

The database contains 20 furniture products across categories including Sofa, Chairs, Tables, Beds and Storage.

---

# REST API

The backend is developed using Node.js and Express.js.

The frontend communicates with the backend through REST APIs.

### Product Endpoints

- GET /api/products
- GET /api/products/:id

These APIs are used to retrieve product information from the backend and display it on the frontend.
