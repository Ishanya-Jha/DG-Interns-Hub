## Project Overview

**Furnisher's Web** is a full-stack furniture e-commerce website developed as the updated web version of my earlier **Furnisher's .NET desktop project**.

The original desktop-based furniture management concept has been redesigned into a modern web application with product browsing, shopping cart, user authentication, checkout, payment demo and order confirmation.

---

## Features

- Responsive furniture e-commerce interface
- Product catalogue with 20 furniture products
- Category-based product browsing
- Product details with images and descriptions
- Colour and quantity selection
- Add to Cart functionality
- Shopping cart management
- Automatic total price calculation
- User registration and login
- Checkout and billing form
- Payment demo interface
- Order confirmation
- REST API integration
- MySQL database integration
